## ✨ Features

- ⚡ **GOD GPT Ultra & Pro** — Two powerful AI chat modes for different use cases
- 🎨 **Image Studio** — Generate high-definition AI art, logos, and concept designs in seconds
- 🔑 **BYOK (Bring Your Own API Key)** — Connect your own API keys, no subscription needed
- 🔄 **Multi-Key Failover System** — If one API key fails, automatically switches to backup key
- 💬 **Unlimited Chat** — Create, rename, save, and export chat conversations
- 🖼️ **Multiple Aspect Ratios** — 1:1, 16:9, 9:16, and 4:3 image formats
- 📥 **Export Chats** — Download conversations as `.txt` files
- 📱 **Works Everywhere** — PC, Android phone, and Tablet supported
- 🌙 **Sleek Dark UI** — Modern cyberpunk-inspired responsive interface

## 🚀 How to Get Started

### Step 1 — Open GOD GPT
👉 Go to **[godgpt-wheat.vercel.app](https://godgpt-wheat.vercel.app/)** on any device.

### Step 2 — Get a Free API Key
Go to [**Google AI Studio**](https://aistudio.google.com/app/apikey) → Sign in with Google → Click **"Create API Key"** → Copy the key.

### Step 3 — Add Your API Key to GOD GPT
Click **"API Settings"** in the sidebar → Paste your key in **"Main API Key"** → Click **"Save Settings & Keys"**.

### Step 4 — Start Chatting!
Choose **GOD GPT Ultra** or **GOD GPT Pro** → Type your message → Get instant AI responses! ⚡

## ❓ FAQ

**Q: Do I need to install anything?**
> No! Just open the website on any browser — PC, Android, or tablet. No installation needed.

**Q: Which API is best for beginners?**
> **Google Gemini** — completely free, no credit card, 1,500 requests/day. Perfect to start with.

**Q: What is the Multi-Key Failover System?**
> If your main API key hits its limit or fails, GOD GPT automatically switches to your backup key so you're never interrupted.

**Q: Is my API key safe?**
> Yes. Your keys are stored only in your browser locally and are never sent to any server.

**Q: Can I use it on my Android phone?**
> Yes! Open Chrome on Android → go to the website → tap the 3-dot menu → "Add to Home Screen" for an app-like experience.

**Q: Can I export my chats?**
> Yes! Click **"Export Chat (.txt)"** to download your full conversation.
